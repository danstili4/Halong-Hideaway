# Halong Hideaway — website concept

Concept redesign for the Halong Hideaway cruise (Lan Ha Bay, Vietnam) by Dan.

- `site/` is the live website (what Netlify publishes).
- `build.py` rebuilds every page in `site/` from one file: edit copy there, then run `python3 build.py`.
- `netlify.toml` tells Netlify to publish `site/`, with long caching for photos and video.

Not indexed by search engines (noindex) so it never competes with the company's real site.
